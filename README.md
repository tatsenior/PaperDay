# 见微 PaperDay

**每天一篇论文，让好奇心慢慢生长。**

选择你感兴趣的研究方向，每天首次打开时，遇见一篇尚未推荐过的近期论文。搭配中文概述、创新点与研究方法，帮助你快速判断是否值得深入阅读。

[下载 Windows 版 v0.1](https://github.com/tatsenior/PaperDay/releases/tag/v0.1) · [反馈问题](https://github.com/tatsenior/PaperDay/issues)

## 功能

- **按兴趣推荐**：计算机科学、物理学、数学、统计与数据科学、生命科学、经济与金融六大领域，每个领域可选 1–4 个二级方向。
- **每日一篇、避免重复**：优先推荐近期发表的论文；同一天重新打开保留当天首次推荐。同一 arXiv 论文的不同版本也会去重。
- **再来一篇**：想多读一点时，一键获取另一篇。
- **中文阅读助手**：中文标题、概述、作者声称的创新点、研究方法与待核实问题。
- **整理阅读足迹**：历史、收藏、已读标记、标题与作者搜索。
- **原文与笔记**：打开论文 PDF、查看摘要页，或导出 Markdown 阅读笔记。

## 下载与开始使用

1. 前往 [v0.1 发布页](https://github.com/tatsenior/PaperDay/releases/tag/v0.1)，下载 **PaperDay-v0.1-Windows.exe**。
2. 双击运行，无需安装 Node.js。首次运行便携包需要短暂解压，请稍候。
3. 选择研究领域和二级方向。
4. 填写自己的模型 API 地址、模型名称及 API Key，开启中文解读；也可选择“稍后配置”，先浏览论文原文。

适用于 **Windows 10 / 11，64 位**。获取新论文和生成解读需要联网；已有历史和已生成解读可离线查看。

### 配置中文阅读助手

在首次引导或“偏好设置”中，填写兼容 **Chat Completions** 接口的模型服务：

| 配置项 | 填写内容 |
| --- | --- |
| API 地址（Base URL） | 服务商提供的接口基础地址，通常以 `/v1` 结尾 |
| 模型名称 | 服务商提供的实际模型 ID |
| API Key | 你自己的服务密钥，本机无鉴权模型可留空 |

程序会补充 `/chat/completions`，也能识别已包含该路径的地址。远程服务需要 HTTPS；本机服务可使用 `http://localhost:11434/v1` 等地址，但需要先自行启动兼容的模型服务。

PaperDay 不内置模型或共享密钥。费用、可用模型和额度由服务商决定。解读保存在本机，再次查看无需重复调用。

## 外观与字号

在“偏好设置 → 外观与阅读”中，可选择深灰薄荷、暮紫、深蓝海盐或暖棕杏色主题。默认基础字号为 16px，阅读正文为 18px；可切换 18px 大字或 20px 特大界面字号，正文和控件会一起缩放。

支持使用 2 MB 以内的 PNG、JPG 或 WebP 图片作为背景，居中铺满并裁剪，可调节显著程度或随时移除。主题、字号和背景即时生效，只保存在本机。

## 推荐规则与解读范围

论文来源为 **arXiv**，当前版本不覆盖所有学科和期刊；部分论文为未经过同行评审的预印本。

默认检索最近 **90 天**，可改为 30、180 或 365 天，按首次发表日期优先推荐。可添加英文关键词，以逗号分隔，匹配标题或摘要，最多使用前 5 个关键词。

每个本地自然日、每组研究偏好保留一篇首次推荐。“再来一篇”新增记录；更换方向后仍按全局历史去重。每次最多检查最新 1000 条结果，范围内没有未推荐论文时会提示调整条件。近期发表是筛选依据，不代表软件能够自动判定学术价值或创新程度。

**中文解读基于标题与摘要生成，没有读取或核验 PDF 全文。** 创新点是对作者声称贡献的整理；实验结论、细节与适用范围请结合原文核对，模型也可能产生错误。

## 数据与隐私

设置、阅读记录、收藏和解读保存在本机，通常位于 `%APPDATA%\PaperDay`，可在设置中打开准确目录。每次写入保留上一版 `.bak` 备份。

- API Key 使用 Windows 系统加密机制保存，不出现在导出笔记中。
- 生成解读时，仅向你配置的模型服务发送该论文的标题和摘要。
- 不上传个人阅读历史，不提供账号登录和跨设备同步。
- 数据文件包含加密密钥，请勿公开；删除数据目录会丢失历史及去重记录。

## 常见问题

**连接不上论文源？**

检查 arXiv 的网络可达性。软件遵循系统代理。断网时，如果有仍符合范围的未推荐缓存，会使用缓存并提示；历史记录仍可查看。

**没有中文解读？**

先配置模型服务，检查 Base URL、模型 ID、API Key 与账户额度，再重试生成。

**关闭后会自动推送吗？**

v0.1 在每天首次打开时推荐，不需要后台常驻，不会自动设置开机启动。

**Windows 提示发布者未知？**

当前发布包未进行商业代码签名。请从本仓库 Releases 获取，并自行判断是否运行。

## 从源码运行

普通用户直接下载 Windows 程序即可。开发者需要 Node.js **22.12+**、npm 和 Windows x64 环境。

```powershell
npm ci
# 若安装脚本策略未自动下载 Electron 运行时：
node node_modules/electron/install.js
npm run dev
```

构建 Windows 便携版：

```powershell
npm run package
```

产物位于 `release/`。界面使用 React，桌面运行时使用 Electron；`core/` 包含推荐、论文检索、本地存储和模型接口逻辑。仓库仅保留应用源码和构建必需文件，便携程序通过 Releases 分发。

## 在 GitHub 上构建

进入仓库的 **Actions → Build Windows → Run workflow**，选择 `main` 后运行。构建完成后，在该次运行页面的 **Artifacts** 下载 `PaperDay-Windows`，其中包含 Windows 程序和 SHA256 校验文件，保留 30 天。

后续发布新版时，先修改 `package.json` 和 `package-lock.json` 的版本号并提交，再创建、推送匹配的 `v*` 标签（例如包版本 `0.2.0` 对应 `v0.2` 或 `v0.2.0`）。GitHub 会自动构建并创建 Release，长期保存下载附件。构建失败时不会创建新的发布页。无需自行配置模型 API Key 或额外的 GitHub 密钥。
